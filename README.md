# Jarvis Assistant

Персональный локальный голосовой ассистент для Windows 11 x64.

**Официальные установщики и обновления:** [открыть выпуски](https://github.com/KidwellyBrand/Jarvis-Assistant-Releases/releases).

by **Kidwelly**

## Если Jarvis ещё не установлен

Откройте последний выпуск и скачайте обе части архива `Jarvis-Assistant-<версия>-win-x64.part1.rar` и `part2.rar` в одну папку. Распакуйте первую часть через WinRAR и запустите полученный файл `Setup-win-x64.exe`.

Полная установка включает .NET, Ollama с qwen2.5:3b, Whisper, Vosk и Piper с русским голосом. При первом запуске создаётся пустая база памяти. Микрофон и сторонние приложения подключаются на вашем ПК.

## Если Jarvis уже установлен

Начиная с 0.9.3 приложение проверяет новые версии при запуске и каждые 30 минут. При наличии новой версии справа сверху появляется колокольчик. Наведите курсор для подсказки или нажмите, чтобы открыть раздел обновлений. Кнопка «Обновить и перезапустить» скачает проверенный пакет и обновит приложение.

Можно также вручную скачать файл `Jarvis-Assistant-<версия>-Update-win-x64.exe` из выпуска и выбрать существующую папку Jarvis. Пакет обновления сохраняет модели, историю, настройки и подключение Spotify.

**Для перехода с 0.9.2 на 0.9.3 пакет Update нужно запустить вручную один раз:** в старой версии ещё нет проверки выпусков.

## Пользовательские данные

История и настройки хранятся отдельно от программы в `%LOCALAPPDATA%\JARVIS`. Они не заменяются обновлениями. Сохранённые сведения и переписка удаляются только по отдельному подтверждению в настройках ассистента.

Этот репозиторий содержит только файлы для пользователей и сведения о выпусках. Исходный код Jarvis и личные данные разработчика не публикуются. Сведения о лицензиях сторонних компонентов включены в полную установку.
